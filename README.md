# 2학년 2반 자리 배치

명단과 자리 배치를 이 PC에 저장하는 Windows Electron 앱입니다.

## 실행과 빌드

```powershell
npm install
npm start
npm run dist
```

설치 파일은 `dist`에 생성됩니다. 개발 실행에서는 자동 업데이트가 비활성화됩니다.

## 명단과 배치 조건

처음 실행하면 **명단 관리** 창이 열립니다. 한 줄에 `101 학생가 여`처럼 학번, 이름, 성별을 입력하고 저장하세요. 명단, 조건, 고정석, 자리 배치는 현재 Windows 사용자 계정에 저장됩니다. 앱을 업데이트하면 이전 버전이 이 PC에 저장한 명단, 기피 관계, 고정석 및 자리를 읽어옵니다. 이전 버전은 붙는 학생 관계를 로컬에 저장하지 않았으므로 앱에서 해당 조건을 입력해야 합니다.

**기피 학생**과 **붙는 학생**에는 한 줄에 학번 두 개를 `101 102`처럼 입력합니다. 등록한 조건은 양방향으로 적용됩니다. 붙는 학생은 좌우 또는 앞뒤 한 칸에 앉습니다. 기피 거리와 고정석 우선 규칙은 기존과 같습니다. 같은 쌍이 두 조건에 속하거나 존재하지 않는 학번을 입력하면 수정할 항목을 표시합니다. 저장한 조건은 명단 관리에서 확인할 수 있습니다.

## 자리 배치

**짝 배치**에서는 각 줄의 1–2번, 3–4번, 5–6번이 한 짝입니다. 짝 구성은 **모두 랜덤**이나 **남남·여여**를 선택할 수 있습니다. 활성 좌석이 모두 짝으로 구성되고 빈자리 없이 남녀 인원이 각각 홀수이면 남녀 짝 한 쌍을 허용합니다.

재배치를 여러 회 실행하면 마지막 회차에 배치 모드와 조건을 적용하고 결과를 저장합니다. 그 전 회차는 고정석을 유지하며 무작위로 배치합니다. 마지막 배치가 불가능하면 재배치 전 자리로 돌아갑니다.

## 앱 업데이트

저장소는 `ryowoo2726-hue/chair_change`로 고정되어 있습니다.

공개 릴리스에서 업데이트를 내려받으며 GitHub 로그인이나 토큰 입력은 필요하지 않습니다.

설치된 앱은 실행할 때 새 버전을 확인합니다. 새 버전 안내에서 **업데이트**를 누르면 다운로드한 뒤 자동으로 설치하고 앱을 다시 엽니다. **나중에**를 누르면 그대로 사용할 수 있습니다. **업데이트 확인** 버튼으로도 확인할 수 있습니다.

## 새 버전 배포

1. `package.json`, `app.js`, `version.json`의 버전을 동일하게 변경합니다.
2. 변경 내용을 push합니다.
3. `v1.2.0` 형식의 태그를 push합니다.
4. GitHub Actions가 NSIS 설치 파일과 업데이트 메타데이터를 Release에 게시합니다.
